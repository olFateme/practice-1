# Frame — HTML & CSS Practice Project

A landing page built with **HTML5** and **CSS3** as my first practical project while learning Front-End Development.

## 📌 About The Project

This project was created as a hands-on exercise to practice the fundamentals of **HTML and CSS**.

The main goal was not to build a production-ready website, but to strengthen my understanding of HTML structure, CSS styling, layouts, positioning, typography, and reusable classes by implementing a complete landing page from scratch.

The project is based on the **Frame** landing page design and was developed for learning and practice purposes.

## 🛠️ Technologies

* HTML5
* CSS3
* Font Awesome
* Google Fonts
* Git & GitHub

## ✨ Sections

The landing page includes:

* Navigation Bar
* Hero Section
* Services
* Features
* Pricing Plans
* Customer Reviews
* Try It Today
* FAQ Section
* Call to Action
* Contact Form
* Footer

## 📚 What I Practiced

During this project, I practiced:

* Semantic HTML structure

* Colors and backgrounds
* Spacing and sizing
* `margin` and `padding`

* Flexbox
* Borders and border-radius

* Positioning
* Hover effects
